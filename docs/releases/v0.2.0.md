# OpenCode Native Swarms v0.2.0

## What ships

The release adds a strict, hash-bound workflow engine with validated DAGs,
layered capabilities and path scopes, structured direct-argv commands,
symlink-safe workspaces, persistent XDG state, approval-bound native sessions,
amend/resume/cleanup lifecycle tools, and adversarial security coverage.

## Security boundary

Workflow sessions are bound to the reserved deny-by-default
`native-swarms-workflow-step` agent. Built-in tools and shell composition are
denied; command execution is available only through exact approved commands.
Remote Git operations, merges, publication, and external writes remain
unsupported. Trusted-project warning: an approved repository script may invoke
its own side effects, so command approval is not a sandbox.

## Migration and limitations

`/swarm` remains available unchanged. Use `/workflow` for persisted runs and
explicit approvals. Background subagents remain experimental and models are
inherited from OpenCode configuration. Automatic resume, unsafe cleanup, and
unverified writer handoffs are intentionally refused.

## Verification

The release candidate is checked with `bun run check`, `bun run package:check`,
and pinned pre-commit hooks. Dogfood evidence is recorded separately in
`docs/dogfood/v0.2.0.md`.
