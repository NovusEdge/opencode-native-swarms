# OpenCode Native Swarms v0.1.0

## What ships

- A model-agnostic `workflow-director` and `/swarm` command.
- Read-only researcher and reviewer workers.
- A tester restricted to fixed, narrow commands in trusted repositories.
- Up to four native background assignments while the parent session remains available.

## Safety boundaries

Stage one cannot edit files, commit, push, merge, create pull requests, or write to external services. Local reads, searches, Git inspection, and test execution are constrained as documented in the README. Test commands execute project code and must be used only in repositories you trust.

## Requirements

- OpenCode 1.18.25 or newer.
- `OPENCODE_EXPERIMENTAL_BACKGROUND_SUBAGENTS=true`.
- Bun, uv, and ripgrep for development and verification.

## Install

Clone the repository, run `bun install`, and register the checkout with `opencode plugin --global "$PWD"`. Restart OpenCode and confirm the four agents and `/swarm` in `opencode debug config`.

## Known limitations

- Installation is from a persistent local checkout; this release is not published to npm.
- Background subagents remain an experimental OpenCode feature.
- Models are intentionally inherited from user configuration and are not pinned.
- Stage one has no writing worker.
