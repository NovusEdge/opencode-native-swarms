# v0.1.1 Tester Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the two canonical Bun checks to the exact `swarm-tester` allowlist, prove the deny boundary, and release the patch as `v0.1.1` after installed-plugin dogfood.

**Architecture:** Extend the existing immutable command-permission object in `src/definitions.ts`; do not add wildcard script matching or a second command parser. Update focused configuration tests, package metadata, and release evidence while preserving the current `/swarm` stage-one contract.

**Tech Stack:** TypeScript, Bun test, OpenCode plugin config types, Markdown, uv-managed pre-commit.

**Spec:** `docs/superpowers/specs/2026-08-29-v0.1.1-v0.2-workflow-engine-design.md`

## Global Constraints

- Keep tester permission `default: deny` via the existing `"*": "deny"` rule.
- Allow only exact, argument-free `bun run check` and `bun run typecheck` additions.
- Do not add model fields, arbitrary scripts, shell composition, package publication, or external writes.
- Preserve user-owned colliding agent and command definitions.
- Use focused tests, `bun run check`, `bun run package:check`, and the full uv pre-commit suite before release.
- Never commit raw transcripts, secrets, absolute local paths, or generated run state.
